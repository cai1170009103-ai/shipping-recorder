# 发货录制终端 v1.2（免费自用版）

按 MFEC 录制终端的用法做的平替：摄像头对着打包台，扫码枪扫快递单号就开始录，
打包完点停止（或直接扫下一单），视频按单号命名保存，时间戳和单号直接烧进画面里，
以后有纠纷直接拿视频当证据。

## 电脑要求

- Windows 10 / 11（你那台 Win11 笔记本就行）
- 一个 USB 摄像头，架在打包台正上方往下拍（你现在 MFEC 用的那个 HBS 4K 摄像头就能直接用）
- Python 3.10 或更新版（安装时勾选 **Add python.exe to PATH**）
  下载：https://www.python.org/downloads/

## 安装（只做一次）

1. 把这个文件夹拷到电脑上，比如 `D:\发货录制终端\`
2. 双击 `install.bat`，等它装完（自动建虚拟环境、装依赖、桌面建快捷方式）
3. 双击桌面的“发货录制终端”打开

想做成单个 exe 发给别的电脑用：装完后双击 `build_exe.bat`，会在 `dist\` 里生成
`发货录制终端.exe`，拷过去双击就能跑，不用装 Python。

## 每天怎么用

1. 打开软件，确认摄像头画面正常（画面里有红色虚线取景框）
2. 扫码枪扫快递单号 → 自动开始录制（画面左下角出现时间戳和单号）
3. 打包、装袋、贴单，正常操作
4. 打包完点“停止”，或直接扫下一单（自动保存上一段并开始新一段）
5. 视频存在设置里的保存文件夹，文件名就是 `单号_日期_时间.mp4`，比如
   `79050415629147_20261124_180153.mp4`
6. 右上角“今日已录”会数今天录了多少单；点“扫码记录”能按单号查到每一段视频

## 设置里能调的东西（点“设置”）

| 设置 | 说明 |
|---|---|
| 摄像头 | 有多个摄像头时选一个 |
| 分辨率 | 3840x2160（4K，你的 HBS 摄像头支持）、1920x1080、1280x720、摄像头默认 |
| 保存文件夹 | 视频存哪，默认是软件旁边 `videos` 文件夹 |
| 终端号 | 烧进视频右上角的编号 |
| 模式 | 打包发货 / 进出库管理 / 退件拆包（烧进视频左上角） |
| 前置预录制 | 扫码前 N 秒的画面也存进视频（默认 5 秒） |
| 扫码后放大 | 扫码后第 2 秒开始，把取景框区域放大 3 秒（看清货品细节）；预览画面同步放大显示并压上“放大显示”大字 |
| 语音播报 | 放大时读“凯博好帅”（小女生甜美音，Edge 在线语音，默认开；设置里可关、可改播报文字）。v1.1 起软件启动后在后台提前合成一次存下来，扫码时直接放存好的，基本秒出声；没网时启动预合成失败也不影响，扫码时现合成（会慢 1~几秒）或走系统语音兜底 |
| 帧数低 | v1.2 起默认开 MJPG 模式：摄像头走压缩格式，省 USB 带宽（很多 4K 摄像头默认不压缩的 YUY2，1080p 就占满 USB 2.0 带宽，出帧只剩几帧/秒）；摄像头插电脑上蓝色的 USB 3.0 口效果最好，不要接分线器 |
| 设置记忆 | v1.1 起摄像头、终端号、保存文件夹等设置存在 exe 旁边，重开软件不用再选；v1.1 起自动裁掉某些摄像头驱动造成的画面黑边 |
| 单段最长 | 默认 200 秒，到时自动保存 |
| 分段时长 | 默认 300 秒一段，超长录制自动另存一段 |
| 无动作自动停 | 画面 N 秒没动静自动停止（0 = 关） |
| 视频保留 | 默认 40 天，到期自动删（0 = 不删） |
| 条码过滤 | 只录符合规则的单号（正则，空 = 不过滤） |
| 全局扫码监听 | 打开后窗口没焦点时扫码也能触发（需要 keyboard 库，安装时自动装） |
| 仅拍照模式 | 扫码只拍一张照片，不录视频；平时点“拍照”按钮也能拍 |
| 镜像 / 取景框 / 运动检测框 | 画面镜像、红色虚线框、检测到动作时画绿框 |

其他用法：
- 重复扫同一单号：延长本次录制，不另存新文件
- 画面左下角时间戳精确到毫秒，单号和终端号都烧进视频里
- 顶部会显示磁盘剩余空间和约可录时长
- 扫码枪使用前把输入法切到英文（和 MFEC 一样）

## 和 MFEC 不一样的地方（先说清楚）

- 没有电子秤、标签打印、OCR 读单号、细节摄像头这些硬件联动功能
- 没有“始终监听别的软件扫码枪”那种系统级钩子之外的花活，全局监听是可选的，
  最稳的还是让本软件窗口保持在前台再扫码
- 4K 录制比较吃 CPU，如果画面卡，就把分辨率降到 1920x1080
- 视频是 mp4（mp4v 编码），Windows 自带播放器、剪映、PotPlayer 都能直接播
- 完全免费，没有到期时间，不用绑卡

## 出问题怎么办

- **摄像头打不开**：先确认摄像头插好了，别的软件（比如 MFEC）有没有正在占用它；
  一个摄像头同一时间只能被一个软件用。设置里换个摄像头试试。
- **画面卡**：分辨率降到 1920x1080 或 1280x720。
- **扫码没反应**：确认输入法是英文，点一下单号输入框让它获得焦点，再扫。
  或者打开设置里的“全局扫码监听”。
- **视频没声音**：本软件只录画面不录声音（发货举证一般只看画面）。
- **双击没反应**：用 `run.bat` 旁边的命令行方式看报错，或把报错截图发给助手。
